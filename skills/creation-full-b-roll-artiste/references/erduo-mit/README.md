# Documents erduo (licence MIT)

Trois documents en anglais repris du projet **erduo-broll-loop-engineering** (copyright 2026 erduo-broll-loop-engineering contributors, licence MIT, texte complet dans `LICENSE`). Ils sont copiés sans modification. Le skill CRÉATION FULL B-ROLL ARTISTE s'en sert comme doctrine de fond, pas comme procédure : le pipeline, les contrats et les rôles du skill restent ceux décrits dans `SKILL.md` et `CONTRACTS.md`.

| Fichier | Ce qu'il apporte |
|---|---|
| `lean-visual-direction.md` | La direction visuelle « matière réelle d'abord » : partir de la chose dont on parle (produit, personne, lieu, capture, document), utiliser les médias fournis ou sous licence avant toute génération, ne jamais remplacer un objet inconnu par une abstraction animée. Composer d'abord l'image fixe la plus lisible, puis n'animer que le changement utile (cinq décisions de mouvement, un seul pic expressif, l'immobilité est un résultat valable). Porter l'image d'un plan à l'autre au lieu de fondre vers le vide. C'est la base de `broll-direction.md` : la règle « jamais de stock pour le produit », le lookbook et l'ordre des sources en découlent. |
| `creative-reviewer.md` | Le rôle du reviewer indépendant : relire le script et la direction dans un contexte vierge, regarder le rendu réel (planche contact, préview en mouvement, échantillons de frames sur les raccords douteux, à taille normale), sans code source ni explications des créateurs. Juger ce qui compte (sujet reconnaissable, un seul point de lecture, causalité du mouvement, continuité entre plans), écrire un `review.md` court avec verdict `ready` ou `revise` et défauts priorisés (plan, temps, problème visible, réparation). Ne jamais déclarer prêt ce qu'on n'a pas vu bouger. Dans le skill, c'est l'esprit de l'étape QC (`qc.md`, `qc_report.md`) et de la lecture de `contact_sheet.jpg` et `preview.mp4` avant livraison. |
| `handoff-template.md` | Le modèle de passation entre étapes : un bloc court (statut, propriétaire, périmètre, identité, artefacts, commande standard, exceptions, étape suivante) qui pointe vers les fichiers au lieu de recopier plans, JSON, logs ou captures. Les scripts du parent produisent les reçus machine (manifestes, hashes, probes) ; les agents créatifs ne les écrivent pas à la main. Jamais de secrets, de longs logs, de scores de goût ni d'affirmation qu'un contrôle technique prouve la qualité visuelle. Le skill reprend ce principe pour ses rapports entre mode 1 (brief) et mode 2 (montage) : dire où sont les fichiers, ce qui reste ouvert, et qui décide ensuite. |

Note : `lean-visual-direction.md` renvoie à un fichier `motion-patterns.md` et à un « runnable starter » du projet d'origine qui ne sont pas inclus ici.
