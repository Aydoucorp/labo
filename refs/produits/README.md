# Photos produit

Un sous-dossier par produit, nommé en minuscules avec des tirets :

```
refs/produits/
└── serviette-microfibre/
    ├── face.jpg
    ├── dos.jpg
    ├── detail-texture.jpg
    └── notes.md        (facultatif : couleurs, matière, dimensions, points à ne pas déformer)
```

- Formats : JPG ou PNG, idéalement ≥ 2000 px sur le plus grand côté, fond neutre.
- Noms de fichiers explicites (`face`, `dos`, `porte`, `packaging`…), sans espaces ni accents.
- Ces fichiers sont les **références de vérité** : ne jamais les modifier ni les écraser.
